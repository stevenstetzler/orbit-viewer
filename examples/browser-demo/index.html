    1. Get a kernel

    NAIF's server doesn't send CORS headers, so this page can't fetch() a kernel directly from naif.jpl.nasa.gov -- browsers block cross-origin reads without them, regardless of caching. Download once (native browser download, unaffected by CORS since it's not read by JS), then pick the file below. Nothing is ever uploaded -- the file stays local and only the small byte ranges spiceJS needs are read from it.

    3. Reference epoch

    –

    Position in time (UTC, ±10 years around now) to view live marker positions and orbit-arc lines at. Each body's orbit-arc line is the exact two-body orbit ellipse implied by its own real state right now -- not sampled real trajectory data over a time span, so it's always a clean closed curve regardless of how far you scrub (loading more bytes on demand if you scrub somewhere not prefetched yet).

    View controls

    Center and Frame pick bodies independently (e.g. positions relative to Earth, oriented as Jupiter rotates is a valid combination); Rotating decides whether Frame's own IAU_<BODY> orientation is actually used, or the fixed, non-rotating ECLIPJ2000 instead. Orbit switches each shown body's arc between an idealized two-body Ellipse (exact right now, always closed) and its real sampled Trajectory over one orbit of whichever body you're centered on -- auto-selected (Ellipse at the Solar System Barycenter, Trajectory anywhere else) but changeable any time. Each row below also has Look (aim the camera at that body without changing any of the above) and From (set Center and Frame to that body at once).
