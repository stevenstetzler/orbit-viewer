spiceJS live demo

DE440 planetary ephemeris, read lazily straight out of a real .bsp kernel file, entirely in this tab.

1. Get a kernel

NAIF's server doesn't send CORS headers, so this page can't fetch() a kernel directly from naif.jpl.nasa.gov -- browsers block cross-origin reads without them, regardless of caching. Download once (native browser download, unaffected by CORS since it's not read by JS), then pick the file below. Nothing is ever uploaded -- the file stays local and only the small byte ranges spiceJS needs are read from it.

Download de440s.bsp (~32 MB)

3. Time window

±30 d

How much time around now to prefetch, and the span each orbit-arc line covers around wherever the "Reference epoch" slider below is currently pointing. Widening this fetches more of the file (still only the bytes needed for these bodies) -- already-fetched bytes are never re-fetched.

–

Position within the time window above (UTC) -- the orbit-arc lines re-center on this epoch as it moves, clipped to the edges of the prefetched window above.

Bodies shown

Click a body to center the view on it. Alt/Option+Click to also lock the view to that body's own rotating IAU_<BODY> frame, instead of the fixed (non-rotating) ECLIPJ2000 orientation every other view uses -- orbit-arc lines are hidden in a rotating frame (a coarse time sample can't meaningfully trace a fast rotation; the live marker positions stay exact regardless).
